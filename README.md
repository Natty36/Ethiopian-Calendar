**Ethiopian Calendar**

A responsive Ethiopian calendar built with HTML, Tailwind CSS, and JavaScript, fetching the current Ethiopian date from the Ethioall API.

**Features**

- Displays current Ethiopian month, year, and day of the week in Amharic.

- Highlights today’s date dynamically.

- Uses flexbox for header and weekdays, and CSS grid for day layout.

**Tech Stack**

HTML5

Tailwind CSS (CDN)

Vanilla JavaScript

Ethioall API (https://api.ethioall.com/date/api)
